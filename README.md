# Password Manager

Консольный менеджер паролей с шифрованием.

## Возможности
- Создание мастер-пароля (хэширование PBKDF2 + соль).
- Шифрование паролей записей через Fernet (AES).
- Добавление, просмотр, поиск и удаление записей.
- Генерация надёжных паролей.

## Установка и запуск

Для управления зависимостями используется [uv](https://docs.astral.sh/uv/).

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ваш_ник/password_manager
```

2. Перейдите в директорию проекта:

```bash
cd password_manager
```

3. Установите зависимости:

```bash
uv sync
```
## Запуск 

4. Создать хранилище

```bash
uv run python src/password_manager/cli.py --init
```

5. Войти и открыть меню

```bash
uv run python src/password_manager/cli.py --unlock
```

6. Просто сгенерировать пароль

```bash
uv run python src/password_manager/cli.py --generate
```

## Тестирование 

```bash
uv run pytest
```

## Использование

| Команда         | Назначение                           |
| --------------- | ------------------------------------ |
| `add`           | Добавить новый пароль                |
| `list`          | Показать список сохранённых сервисов |
| `get <name>`    | Получить пароль указанного сервиса   |
| `delete <name>` | Удалить пароль указанного сервиса    |
| `generate`      | Сгенерировать надёжный пароль        |
| `exit`          | Завершить работу                     |
